# 💬 Real-Time Chat Application

A full-stack real-time chat application built using the **MERN stack**, **Socket.IO**, **Clerk**, and **ImageKit**. It provides real-time messaging, online user presence, media sharing, and a customizable chat experience.

## ✨ Features

- 💬 Real-time messaging with Socket.IO
- 🔐 User authentication with Clerk
- 🟢 Online user presence
- 🖼️ Image & video sharing
- 📤 Media uploads with ImageKit
- 🌙 Light & Dark mode
- 🌈 11 themes & 13 wallpapers
- ⌨️ Optional keyboard sounds
- 🔔 Clerk webhooks
- ⏰ Cron jobs
- 📱 Responsive UI

## 🛠️ Tech Stack

**Frontend:** React, Tailwind CSS, Hero UI, Zustand, Socket.IO Client

**Backend:** Node.js, Express.js, Socket.IO

**Database:** MongoDB Atlas

**Authentication:** Clerk

**Media:** ImageKit

**Deployment:** Render
